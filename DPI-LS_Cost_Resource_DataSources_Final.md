## 2. Cost Parameters Supported

### Model Cost
* **Definition:** The direct API cost incurred by the LLM inference based on pricing tiers.
* **How DPI-LS Calculates It:** Based on LLM input/output tokens multiplied by Bedrock model pricing.
* **Backend Source:** `api/scoring.py` / `dpi_ls/cost_calculator.py`
* **Database Source:** `AgentObservation.cost.model_cost` in `score_history` table (JSON `C` dict).
* **Dashboard Source:** DPI-LS Dashboard "Model Cost (AI Spend)" Widget.
* **Resource Used:** Langfuse, Prometheus (`model_cost` Gauge).

### Token Cost
* **Definition:** Cost of the raw tokens processed by the infrastructure.
* **How DPI-LS Calculates It:** Total Tokens * Cost Factor.
* **Backend Source:** `api/scoring.py`
* **Database Source:** `AgentObservation.cost.token_cost`
* **Dashboard Source:** Prometheus metrics browser.
* **Resource Used:** Prometheus (`token_cost` Gauge).

### Prompt Cost
* **Definition:** Cost associated exclusively with the input tokens sent to the LLM.
* **How DPI-LS Calculates It:** Input Tokens * Prompt Token Price (e.g., $0.000005/token).
* **Backend Source:** `api/scoring.py`
* **Database Source:** `AgentObservation.cost.input_tokens`
* **Dashboard Source:** Prometheus & Grafana.
* **Resource Used:** Prometheus (`prompt_cost` Gauge), Langfuse.

### Completion Cost
* **Definition:** Cost associated exclusively with the output tokens generated by the LLM.
* **How DPI-LS Calculates It:** Output Tokens * Completion Token Price (e.g., $0.000015/token).
* **Backend Source:** `api/scoring.py`
* **Database Source:** `AgentObservation.cost.output_tokens`
* **Dashboard Source:** Prometheus & Grafana.
* **Resource Used:** Prometheus (`completion_cost` Gauge), Langfuse.

### AI Cost Per Output
* **Definition:** The average model cost per successfully completed unit of work (Task).
* **How DPI-LS Calculates It:** `model_cost / max(completed_tasks, 1)`
* **Backend Source:** `api/scoring.py`
* **Database Source:** Extracted live from `AgentObservation.cost` and `AgentObservation.tasks`.
* **Dashboard Source:** Prometheus.
* **Resource Used:** Prometheus (`AI_cost_per_output` Gauge).

### Human Cost Per Output
* **Definition:** The baseline human salary equivalent cost for performing the same task manually.
* **How DPI-LS Calculates It:** Extracted from baseline system settings.
* **Backend Source:** `contract/settings.py` / `api/scoring.py`
* **Database Source:** `AgentBaseline.human_output_per_period`
* **Dashboard Source:** Prometheus.
* **Resource Used:** Prometheus (`Human_cost_per_output` Gauge).

### Total Cost Of Ownership (TCO)
* **Definition:** Comprehensive cost including model inference API spend plus the remaining human labor overhead.
* **How DPI-LS Calculates It:** `model_cost + human_cost`
* **Backend Source:** `api/scoring.py`
* **Database Source:** Derived natively in Backend.
* **Dashboard Source:** DPI-LS Dashboard "Total Cost of Ownership" Widget.
* **Resource Used:** Prometheus (`total_cost_of_ownership` Gauge), Grafana.

### Utilization
* **Definition:** The resource efficiency of the agent relative to infrastructure usage.
* **How DPI-LS Calculates It:** System CPU/Memory footprint per request.
* **Backend Source:** `api/scoring.py` (Exported Metric).
* **Database Source:** Real-time OTel metrics.
* **Dashboard Source:** Grafana.
* **Resource Used:** Prometheus (`utilization` Gauge).
